# Product Overview

Suna is an open-source generalist AI Worker platform that enables users to create, configure, and run AI agents for various tasks.

## Core Capabilities

- **AI Agent Management**: Create, configure, and version AI agents with custom system prompts and tool configurations
- **Conversation Threading**: Manage multi-turn conversations between users and AI agents
- **Tool Execution**: Extensible tool system supporting web search, file operations, code execution, and external API integrations
- **Background Processing**: Async agent execution via Redis-backed job queue (Dramatiq)
- **Sandbox Environments**: Secure code execution via Daytona cloud development environments
- **Multi-Provider LLM Support**: Unified interface for OpenAI, Anthropic, AWS Bedrock, Groq, OpenRouter, Gemini, and xAI

## Business Features

- Credit-based billing system with Stripe integration
- Subscription tiers and trial management
- Agent marketplace for sharing and discovery
- Knowledge base management for agent context
- Trigger system for automated agent execution
- Google Docs/Slides integration for document generation

## Target Users

Developers and businesses building AI-powered automation workflows, document generation, and conversational AI applications.
